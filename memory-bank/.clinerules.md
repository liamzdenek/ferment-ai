# Ferment AI Project Intelligence

This file captures important patterns, preferences, and project intelligence that help work more effectively with the Ferment AI project.

## Project Patterns

### Configuration Patterns

1. **Use AWS CDK Constructs Library**
   - Use the actual "constructs" npm package from AWS CDK
   - Follow the CDK pattern of `new ConstructType(scope, id, props)`
   - Maintain proper scope hierarchy

2. **L1/L2/L3 Construct Hierarchy**
   - L1: Core primitives (VirtualModel, AgentContext, Tool, etc.)
   - L2: Combinations of L1 constructs for common patterns
   - L3: High-level, domain-specific constructs

3. **Declarative Over Imperative**
   - Configuration should be declarative, describing what should exist
   - Runtime logic should be separate from configuration

### Journal Patterns

1. **Journal as Source of Truth**
   - All system state derives from the journal
   - Journal is append-only during execution
   - Events are categorized by type

2. **Event Publishing**
   - Components publish events to the journal
   - No direct state modification
   - Clear event structure with source, target, payload

3. **Event Subscription**
   - Components subscribe to relevant events
   - Derive state from events
   - React to state changes

### API Patterns

1. **Completely Stateless API**
   - No server-side state storage
   - Client maintains and passes journal state
   - Each request is self-contained

2. **Streaming Updates**
   - Real-time streaming of events
   - Journal updates included in stream
   - Final journal state returned at completion

3. **Clean Separation of Concerns**
   - API layer separate from execution logic
   - Clear interfaces between components
   - Minimal dependencies

## Known Issues and Workarounds

### 1. TypeScript Module Resolution

**Issue**: When using the 'node16' or 'nodenext' module resolution strategy, TypeScript requires explicit file extensions in import paths.

**Error Message**: 
```
Relative import paths need explicit file extensions in ECMAScript imports when '--moduleResolution' is 'node16' or 'nodenext'. Did you mean './file.js'?
```

**Workarounds**:
1. Add `.js` extensions to all import paths:
   ```typescript
   // Before
   import { Something } from './something';
   
   // After
   import { Something } from './something.js';
   ```

2. Change the module resolution strategy in tsconfig.json:
   ```json
   {
     "compilerOptions": {
       "moduleResolution": "node",
       "module": "esnext"
     }
   }
   ```

### 2. Jest Configuration Issues

**Issue**: The Jest plugin in the Nx configuration is having trouble processing the project graph.

**Error Message**:
```
Failed to process project graph.
An error occurred while processing files for the @nx/jest/plugin plugin.
- packages/constructs/jest.config.ts: undefined
```

**Potential Solutions**:
1. Simplify the Jest configuration
2. Install missing dependencies
3. Update the Nx configuration

### Construct System

The construct system is the foundation of Ferment AI:

1. **Base Construct**
   ```typescript
   export abstract class FermentConstruct extends Construct {
     public readonly description?: string;

     constructor(scope: Construct, id: string, props: FermentConstructProps = {}) {
       super(scope, id);
       this.description = props.description;
     }

     public override toString(): string {
       return `${this.node.id}${this.description ? ` (${this.description})` : ''}`;
     }
   }
   ```
